# พระนคร Journey — Smart Tourist Route

ออกแบบใหม่โดยใช้ Template แนว Old Bangkok Travel Magazine แต่เปลี่ยน Workflow ให้คล้ายเว็บตัวอย่างที่ผู้ใช้ส่งมา

## Workflow
1. Search Route — เลือกต้นทาง/ปลายทาง และค้นหา
2. Compare Options — แสดงเส้นทางที่เป็นไปได้และเปรียบเทียบระยะทาง
3. Trip Detail — แสดง Timeline และจุดที่ผ่าน
4. Graph Theory — แสดง Vertex, Edge, Adjacency List และ Path
5. Tree Structure — แสดง Root, Parent, Child, Leaf และ Root-to-Leaf Path
6. Weighted Graph — อธิบาย Edge Weight และ Dijkstra

## ข้อกำหนด
- Vertex 6 จุด
- Edge 8 เส้น
- Adjacency List ด้วย JavaScript
- Path อย่างน้อย 1 เส้นทางและอธิบายความหมาย
- Tree อย่างน้อย 3 ระดับ
- Root / Parent / Child / Leaf
- Weighted Graph + Dijkstra
- เลือกต้นทาง/ปลายทางและแสดงจุดที่ผ่าน

หมายเหตุ: ระยะทางเป็นข้อมูลตัวอย่างเพื่อสาธิตหลักการ ไม่ใช่ข้อมูลนำทางแบบเรียลไทม์
